S1 · LO1Import the three core libraries with their standard aliases▼

State which three libraries the pipeline imports, their conventional aliases, and what each is used for downstream.

  • numpy as np — numerical arrays and math; used later for np.nan (the missing-value marker) and np.array(...).
  • matplotlib.pyplot as plt — plotting library, imported by convention as part of the standard template even though this script never plots.
  • pandas as pd — tabular data loading and manipulation; provides pd.read_csv() and the DataFrame.
S2 · LO2Load the CSV and separate features (X) from the target (y)▼

Explain how the dataset is read and how the feature matrix X and dependent vector y are created.

  • pd.read_csv('Data.csv') — reads the file into a pandas DataFrame stored in dataset.
  • X = dataset.iloc[:, :-1].values — every row, every column except the last → the feature matrix (Country, Age, Salary).
  • y = dataset.iloc[:, -1].values — every row, only the last column → the dependent variable (Purchased).
  • .iloc / .values — .iloc selects by integer position (not label); .values returns the underlying NumPy array that scikit-learn expects.
S3 · LO3Fill missing numeric values with SimpleImputer (mean strategy)▼

Describe how missing Age/Salary values are replaced and why only those columns are touched.

  • from sklearn.impute import SimpleImputer — the imputer class lives in sklearn.impute.
  • SimpleImputer(missing_values=np.nan, strategy='mean') — replaces each NaN with the mean of its column.
  • X[:, 1:3] — applied only to columns 1–2 (Age, Salary); column 0 (Country) is text and has no mean.
S3 · LO4Explain fit vs transform (and fit_transform)▼

State the difference between fit, transform, and fit_transform and why order matters.

  • fit() — learns parameters from the data (here, the column means) but changes nothing.
  • transform() — applies those learned parameters to actually replace the values.
  • fit_transform() — does both in one call; the imputer example separates them (imputer.fit(...) then imputer.transform(...)) to make the two steps explicit.
S4 · LO5One-hot encode the independent categorical column via ColumnTransformer▼

Explain how the Country column is one-hot encoded and what each argument does.

  • ColumnTransformer (from sklearn.compose) — applies a transformer to specific columns only.
  • transformers=[('encoder', OneHotEncoder(), [0])] — one-hot encode column [0] (Country); OneHotEncoder is from sklearn.preprocessing.
  • remainder='passthrough' — keep all other columns (Age, Salary) unchanged instead of dropping them.
  • X = np.array(ct.fit_transform(X)) — run it and force the result back into a NumPy array.
S4 · LO6Justify one-hot encoding and locate the new dummy columns▼

Say why one-hot encoding is used instead of numeric labels, and where the resulting columns appear.

  • Why one-hot — labeling France/Germany/Spain as 0/1/2 would imply a false order/magnitude; one-hot avoids that by making each category its own 0/1 column.
  • Three new columns — France, Germany, Spain become three binary dummy columns.
  • Position — the dummy columns are placed at the front (columns 0–2); Age and Salary shift to become columns 3 and 4.
S5 · LO7Label-encode the dependent variable▼

Explain how the Purchased column is encoded and why LabelEncoder is appropriate here.

  • LabelEncoder (from sklearn.preprocessing) — converts category labels to integers.
  • y = le.fit_transform(y) — turns No/Yes into 0/1 (alphabetical: No=0, Yes=1).
  • Why it's fine for y — the dependent variable is a single target column, so a false ordinal order is not a concern the way it is for feature columns.
S6 · LO8Split the data into training and test sets▼

Describe train_test_split and what its key arguments control.

  • from sklearn.model_selection import train_test_split — the split function's module.
  • test_size = 0.2 — 20% of rows go to the test set, 80% to training.
  • Four outputs — X_train, X_test, y_train, y_test in that fixed order.
S6 · LO9Explain random_state and reproducibility▼

Say what random_state does and why it is fixed.

  • What it does — train_test_split shuffles the rows before splitting (shuffle=True by default); random_state seeds that shuffle so the same split happens every run.
  • Any integer works — the specific value (0, 1, 42) is arbitrary; what matters is using the same one consistently.
  • This module — the worked file uses random_state = 1; the template uses 0. Different seeds give different rows in each set.
S7 · LO10Apply feature scaling with StandardScaler▼

Explain what standardization does and how StandardScaler is applied.

  • StandardScaler (from sklearn.preprocessing) — standardizes values to mean 0, unit variance: z = (x − mean) / std.
  • Why — puts Age and Salary on the same scale so large-magnitude features (Salary) don't dominate models that are distance/gradient based.
  • Applied after the split — scaling comes last, on the already-split data.
S7 · LO11Scale only numeric columns, and fit the scaler on training data only▼

Explain the two subtle choices in the scaling step.

  • Only columns [:, 3:] — scaling is applied to Age/Salary (columns 3+), not the one-hot dummy columns, which are already 0/1 and should stay interpretable.
  • fit_transform on X_train, transform on X_test — the scaler learns mean/std from the training set only, then re-uses them on the test set.
  • Why — fitting on the test set too would leak test information into training (data leakage) and give an over-optimistic evaluation.

Module 3 · The 7-stage preprocessing pipeline

📦 Stage 1 — Importing the libraries▼
import numpy as np import matplotlib.pyplot as plt import pandas as pd

Terms

  • numpy (np) — numerical computing library; arrays, np.nan, np.array().
  • matplotlib.pyplot (plt) — plotting; part of the standard import block by convention even though it is unused in this script.
  • pandas (pd) — data loading / DataFrames; provides pd.read_csv().
📄 Stage 2 — Importing the dataset▼
dataset = pd.read_csv('Data.csv') X = dataset.iloc[:, :-1].values y = dataset.iloc[:, -1].values print(X) print(y)

Terms

  • read_csv — loads the CSV into a DataFrame. The dataset has 4 columns: Country, Age, Salary, Purchased (10 rows).
  • iloc[:, :-1] — integer-location slice: all rows, all columns except the last → features (X).
  • iloc[:, -1] — all rows, last column only → dependent variable (y).
  • .values — returns the underlying NumPy array from the pandas object.
  • Missing data present — one Age and one Salary value are nan in the raw data (handled in Stage 3).
🩹 Stage 3 — Taking care of missing data▼
from sklearn.impute import SimpleImputer imputer = SimpleImputer(missing_values=np.nan, strategy='mean') imputer.fit(X[:, 1:3]) X[:, 1:3] = imputer.transform(X[:, 1:3]) print(X)

Terms

  • SimpleImputer — from sklearn.impute; fills missing values.
  • missing_values=np.nan — which value counts as "missing".
  • strategy='mean' — replace with the column mean (other options: median, most_frequent, constant).
  • X[:, 1:3] — Age & Salary columns only (column 0, Country, is text).
  • fit then transform — fit learns the means; transform writes them back into the array.
🔤 Stage 4 — Encoding the independent variable▼
from sklearn.compose import ColumnTransformer from sklearn.preprocessing import OneHotEncoder ct = ColumnTransformer(transformers=[('encoder', OneHotEncoder(), [0])], remainder='passthrough') X = np.array(ct.fit_transform(X)) print(X)

Terms

  • ColumnTransformer — from sklearn.compose; applies a transformer to selected columns.
  • OneHotEncoder — from sklearn.preprocessing; turns a category column into binary dummy columns.
  • transformers=[('encoder', OneHotEncoder(), [0])] — name, transformer, target column list.
  • remainder='passthrough' — keep untouched columns; the default 'drop' would delete them.
  • Result — three dummy columns (France, Germany, Spain) move to the front; Age/Salary become columns 3 & 4.
🏷️ Stage 5 — Encoding the dependent variable▼
from sklearn.preprocessing import LabelEncoder le = LabelEncoder() y = le.fit_transform(y) print(y)

Terms

  • LabelEncoder — from sklearn.preprocessing; encodes labels as integers.
  • fit_transform(y) — learns the label set and converts in one call.
  • Result — No → 0, Yes → 1 (assigned alphabetically).
✂️ Stage 6 — Splitting into Training & Test sets▼
from sklearn.model_selection import train_test_split X_train, X_test, y_train, y_test = train_test_split(X, y, test_size = 0.2, random_state = 1) print(X_train) print(X_test) print(y_train) print(y_test)
⚠️ Source conflict — worked file: random_state = 1; template file: random_state = 0. Canonical here = 1 (it produced the notebook's printed splits). Verify against the answer key.

Terms

  • train_test_split — from sklearn.model_selection.
  • test_size = 0.2 — 20% test / 80% train (8 train rows, 2 test rows here).
  • random_state = 1 — seeds the shuffle so the split is reproducible.
  • Return order — X_train, X_test, y_train, y_test.
📏 Stage 7 — Feature Scaling▼
from sklearn.preprocessing import StandardScaler sc = StandardScaler() X_train[:, 3:] = sc.fit_transform(X_train[:, 3:]) X_test[:, 3:] = sc.transform(X_test[:, 3:]) print(X_train) print(X_test)

Terms

  • StandardScaler — from sklearn.preprocessing; standardizes to mean 0, unit variance.
  • [:, 3:] — scale Age/Salary only, not the 0/1 dummy columns.
  • fit_transform(X_train) vs transform(X_test) — fit on train only, then apply to test (avoids data leakage).
  • Order — scaling is done after the split, not before.
