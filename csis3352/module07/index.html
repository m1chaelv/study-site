S1 · LO1Define K-Nearest Neighbors▼

Explain what K-NN is, which tasks it handles, and how it reaches an answer for a new point.

  • What it is — a simple, intuitive supervised learning algorithm.
  • Two tasks — used for both classification and regression.
  • How it predicts — a new point's outcome is based on the outcomes of its K closest neighbors.
  • Why it matters — one of the simplest algorithms in machine learning, and a great way to build intuition for classification.
S1 · LO2Explain why K-NN is a "lazy," instance-based learner▼

Describe what K-NN does during training and when the real work happens.

  • Lazy learning — K-NN doesn't build an explicit model during training.
  • "Training" = storing — it just keeps the training examples and their labels.
  • Instance-based — predictions come straight from the stored examples themselves, not from a learned formula.
  • Work happens at prediction time — each new point needs distances to the stored data, which is why prediction can be slow on large datasets.
S1 · LO3Walk through the four steps of K-NN▼

Classify a new point step by step and explain the deciding vote.

  • Step 1 · Choose K — the number of neighbors to look at.
  • Step 2 · Calculate distances — from the new point to every point in the training data.
  • Step 3 · Find the K closest — those are the "nearest neighbors."
  • Step 4 · Decide — classification takes a majority vote of the neighbors' classes; regression averages their values.
  • Example — K = 3 with 2 neighbors in Class 0 and 1 in Class 1 → majority is Class 0 → the new point is Class 0.
S1 · LO4Contrast K-NN classification and regression▼

Explain what stays the same and what changes between the two tasks.

  • Classification — predicts a class label by majority vote among the K nearest neighbors.
  • Regression — predicts a continuous value by averaging the K nearest neighbors' values.
  • Same core idea — finding the closest points is exactly the same in both.
  • Only the last step changes — vote for classification, average for regression.
S2 · LO5Choose a good value of K▼

Explain the trade-off between small and large K and how K is usually picked.

  • Small K (e.g., K = 1) — sensitive to noise; it can overfit and be easily swayed by outliers (jagged boundary).
  • Large K (e.g., K = 15) — smoother, but can blur the boundary between classes and may underfit.
  • Common practice — try several values of K and use cross-validation to pick the best one.
  • Odd K for binary problems — K is usually odd in binary classification, to avoid tie votes.
S2 · LO6Calculate Euclidean and Manhattan distance▼

Write both formulas, explain what each measures, and compute them for a pair of points.

  • Distance decides neighbors — it's how K-NN decides who counts as a "neighbor."
  • Euclidean — d(p,q) = √( Σ (pᵢ − qᵢ)² ): straight-line distance, the most common choice for K-NN.
  • Manhattan — d(p,q) = Σ |pᵢ − qᵢ|: sums absolute differences, like navigating a city grid.
  • Different metrics, different answers — a different metric can pick different neighbors and give a different prediction.
  • Worked example — (1, 1) to (4, 5): Euclidean = √(3² + 4²) = 5; Manhattan = 3 + 4 = 7.
S2 · LO7Explain why feature scaling matters for K-NN▼

Explain what goes wrong without scaling and what to do about it.

  • All about distance — K-NN relies entirely on distance calculations.
  • Big scales dominate — a feature on a larger scale (income in the thousands) drowns out a smaller-scale feature (age).
  • The fix — always apply normalization (min-max) or standardization (z-score) before K-NN, so features contribute equally.
  • Common trap — skipping it is one of the most common beginner mistakes with this algorithm.
  • Class data example — unscaled, an 11-year age gap counts as 11 but a $2,000 salary gap counts as 2,000; after scaling they're about 1.09 and 0.06.

  • Multi-class — naturally handles multi-class problems.

🧭 Part 1 — What K-NN Is & How It Works▼

What it is

  • K-Nearest Neighbors (K-NN) — a simple, intuitive supervised learning algorithm used for both classification and regression.
  • How it predicts — a new point's outcome is based on the outcomes of its K closest neighbors.
  • Why it's taught — one of the simplest algorithms in machine learning, and a great way to build intuition for classification.
🧩 Study aid — "supervised" (Module 1). Supervised learning learns from labeled data, where the correct answer is already known. K-NN needs those labels: they're what the neighbors vote with.

"Lazy learning"

  • No explicit model — K-NN doesn't build a model during training; it just stores the training data.
  • Instance-based — every prediction is made directly from the stored examples ("instances").
  • The work moves to prediction time — each new point has to be compared with the stored data, which is why prediction can be slow on large datasets (Part 4).

The four steps

StepWhat happensIn the picture above
1 · Choose KPick the number of neighbors to look at.K = 3
2 · Calculate distancesMeasure the distance from the new point to every point in the training data.Star → every shape
3 · Find the K closestKeep the K points with the smallest distances — the "nearest neighbors."The 3 shapes inside the dashed circle
4 · Vote (or average)Classification: majority vote of the neighbors' classes. Regression: average of their values.2 circles vs 1 triangle → Class 0

The lecture sums it up in three stages: store the data (keep all training examples and their labels) → find the K nearest neighbors → majority vote (predict the class with the most neighbors).

⚠️ Internal inconsistency in the lecture: one of its K = 3 pictures also circles a green square inside the neighborhood, even though the same picture's tally says 0 green neighbors. Go by the tally and the rule: with K = 3, only the 3 closest points vote.

🧩 Study aid — terms from Module 5. Overfitting = the model memorizes the training data, noise included, and does worse on new data. Underfitting = the model is too simple to capture the pattern. ⚠️ Name trap: the k in "k-fold cross-validation" (how many parts the data is split into) is not the K in K-NN (how many neighbors vote). You can use 5-fold cross-validation to compare K = 3, 5, 7 …

📏 Part 3 — Distance Metrics & Feature Scaling▼

Distance: how K-NN decides who's a neighbor

MetricFormulaWhat it measures
Euclideand(p,q) = √( Σ (pᵢ − qᵢ)² )Straight-line distance — the most common choice for K-NN.
Manhattand(p,q) = Σ |pᵢ − qᵢ|Sums the absolute differences — like navigating a city grid.
  • pᵢ and qᵢ — the two points' values for feature i; Σ adds up over every feature.
  • Why it matters — different distance metrics can lead to different neighbors, and therefore different predictions.
📌 Practice numbers: the points above and below are made up. Only the formulas come from the lecture.
PointsDifferencesEuclideanManhattan
(1, 1) → (4, 5)3, 4√(9 + 16) = 53 + 4 = 7
(0, 0) → (6, 8)6, 8√(36 + 64) = 106 + 8 = 14
(2, 7) → (2, 3)0, 4√(0 + 16) = 40 + 4 = 4
(1, 2, 3) → (3, 4, 4)2, 2, 1√(4 + 4 + 1) = 32 + 2 + 1 = 5
💡 Study aid — memory trick. Euclidean = as the crow flies (square, add, square-root). Manhattan = as the taxi drives (just add the gaps). Manhattan is never shorter than Euclidean; they're equal only when the points differ in a single feature (third row).

Why feature scaling matters for K-NN

  • K-NN relies entirely on distance calculations.
  • Big scales dominate — a feature on a larger scale (e.g., income in the thousands) dominates the distance, drowning out smaller-scale features (e.g., age).
  • The fix — always apply normalization (min-max) or standardization (z-score) before using K-NN, so both features contribute equally.
  • Common trap — forgetting to scale is one of the most common beginner mistakes with this algorithm.

The class data shows it. Same new person, two possible neighbors:

  • Unscaled — an 11-year age gap adds just 11 to the distance, but a $2,000 salary gap adds 2,000. Neighbor A (11 years older) "wins," even though B is the same age and earns almost the same.
  • Scaled — each gap is divided by that feature's spread (training std: age ≈ 10.1, salary ≈ 34,491). Now the age gap ≈ 1.09 and the salary gap ≈ 0.06, so B is correctly the nearer neighbor.
🧩 Study aid — the two scaling formulas (Module 2). Min-max normalization: x' = (x − min) / (max − min) → squeezes values into [0, 1]; sensitive to outliers. Z-score standardization: z = (x − μ) / σ → mean 0, standard deviation 1; more robust to outliers. The class notebook uses z-score (StandardScaler).
💡 Study aid — K-NN without scaling (not run in class). Training the same K = 5 model on the raw ages and salaries drops test accuracy from 0.93 to 0.83 (confusion matrix [[59 9] [8 24]]). For the 30-year-old earning $87,000, the five raw-data neighbors all earn $86,000–$88,000 but range in age from 18 to 41 — age barely counts.

C · plt.contourf(...)Flattens the grid, scales it, predicts every point with K-NN, folds the answers back into the grid shape, and paints the background: red = predicted 0, green = predicted 1.
D · plt.scatter loopPlots each real point in its true color: red for 0, green for 1.
  • Boundary shape — irregular and jagged, with small pockets. K-NN follows whatever the local neighbors say, so the edge bends around clusters of points instead of being a straight line.
  • Pattern — younger, lower-salary people fall in red (didn't purchase); older people and high earners fall in green.
  • Misclassified points — a dot on the wrong color. On the test plot those are the 4 false positives (red dots on green) and 3 false negatives (green dots on red).

  • The warning above each chart — the same harmless Matplotlib c-argument warning as Module 6.
