S1 · LO4Explain why linear regression fails at classification▼

Give the problems with fitting a straight line to class labels and what logistic regression does instead.

  • Unbounded output — linear regression can output anything from −∞ to +∞, which is not a valid probability.
  • Impossible values — its straight line can predict values below 0 or above 1.
  • Poor separation — a straight line doesn't naturally separate two classes well, especially with outliers, which it can misclassify.
  • The fix — we need an output squeezed between 0 and 1. Logistic regression's sigmoid approaches 0 and 1 but never crosses them.
S2 · LO5State the sigmoid function and its key values▼

Write the sigmoid, explain what it does, and give its value at the three landmark inputs.

  • Formula — σ(z) = 1 / (1 + e−z).
  • What it does — takes any real number z and squashes it into a range between 0 and 1.
  • Read as probability — the output is interpreted directly as a probability.
  • Landmarks — large positive z → near 1 (z = 6 → ≈ 1) · large negative z → near 0 (z = −6 → ≈ 0) · z = 0 → exactly 0.5.
  • Shape — an S-curve; in the steep middle, a small change in input causes a large change in probability.
S2 · LO6Trace the two-step process: linear part → sigmoid▼

Show how a row of feature values becomes a probability, and name what the model learns.

  • Step 1 · linear part — z = w1x1 + w2x2 + … + wnxn + b: a weighted sum of the inputs, exactly like linear regression.
  • Step 2 · squash — p = σ(z) = 1 / (1 + e−z) turns z into a probability.
  • What's learned — the best weights (w) and bias (b), found during training.
  • The foundation — linear combination, then sigmoid: this two-step process is the whole basis of logistic regression.
S2 · LO7Apply the threshold and explain the trade-off▼

Turn a probability into a class, and explain when to move the threshold.

  • Probability first — the model outputs a probability, for example p = 0.82.
  • Threshold — the probability becomes a class using a threshold, commonly 0.5.
  • Decision rule — p ≥ 0.5 → Class 1 · p < 0.5 → Class 0. At exactly 0.5 the model is equally unsure; that's the decision boundary.
  • Adjustable — the threshold can move depending on whether false positives or false negatives matter more.
  • Trade-off — lower threshold: fewer false negatives, more false positives · higher threshold: fewer false positives, more false negatives.
S3 · LO8Explain log loss and how training uses it▼

Write the cost function, explain what it rewards and punishes, and how the model minimizes it.

  • Formula — Cost = −[ y·log(p) + (1 − y)·log(1 − p) ], where y = the true label (0 or 1) and p = the predicted probability.
  • Name — binary cross-entropy, also called log loss: logistic regression's cost function.
  • What it measures — how wrong a single prediction is; during training it's averaged across all data points.
  • Penalty shape — heavily penalizes confident, wrong predictions, much more than a small, cautious miss.
  • Training — the model adjusts its weights with gradient descent to minimize this cost over many training iterations.
S3 · LO9Distinguish binary, multinomial, and ordinal▼

Classify a problem as one of the three types of logistic regression.

  • Binary — exactly two classes; the most common case (spam vs. not spam, 0 vs. 1).
  • Multinomial — three or more classes with no natural order (cat vs. dog vs. bird).
  • Ordinal — three or more classes with a natural order (low vs. medium vs. high risk).
  • Telling them apart — count the classes first (two → binary); with three or more, ask whether they have a ranking (yes → ordinal, no → multinomial).
S3 · LO10Name real-world uses and summarize the method▼

Match logistic regression to its real-world uses and summarize how it works end to end.

  • Detect & diagnose — spam detection (spam or not) · medical diagnosis (disease present or absent).
  • Decide & predict behavior — credit scoring (approve or deny a loan) · customer churn (stay or leave) · ad targeting (click or not).
  • Core pipeline — linear combination → sigmoid → probability → threshold → class.
  • Trained by — minimizing log loss with gradient descent.
  • Its role — a simple, fast, highly interpretable baseline model for binary classification.

🧭 Part 1 — What Logistic Regression Is & When to Use It▼

What it is

  • Definition — a statistical / machine learning algorithm used to predict the probability of a categorical outcome.
  • Classification, not regression — despite the name, it's used for classification tasks.
  • Output — a probability between 0 and 1, which is then mapped to a class label.
  • Why it's popular — one of the most widely used, fast, and interpretable models in industry.
  • Goal — estimate the probability of an outcome (between 0 and 1) and make a decision.
⚠️ Not explained in the source: what makes a model "interpretable" — the deck uses the word without defining it.

Classification or regression? Clearing up the name

The name is genuinely confusing: logistic regression is built on regression math, but it solves classification problems.

Linear regressionLogistic regression
PredictsA continuous numberA category — by predicting the probability of belonging to a class
ExamplesA price, a temperature, a scoreYes / no, spam / not spam
Use when the target is…ContinuousCategorical

When do we use it?

Best suited for binary classification — problems with exactly two possible outcomes. It can also be extended to multi-class problems (see the types in Part 3).

AreaThe two outcomes
📧 EmailSpam or not spam
🩺 MedicalDisease present or not present
🏦 FinanceLoan approved or denied
📣 MarketingCustomer will churn or stay

Why it works: it models the relationship between the features and the probability of an outcome using an S-shaped (sigmoid) curve.

Why not just use linear regression?

  • Unbounded output — linear regression can output any value from −∞ to +∞. That isn't a valid probability, which must be in [0, 1]. It can predict "impossible" values below 0 or above 1.
  • Poor separation — a straight line doesn't naturally separate two classes well, especially with outliers. A poor fit can misclassify the outliers.
  • The fix — we need an output squeezed between 0 and 1. That's exactly what logistic regression provides: its S-curve asymptotically approaches 0 and 1 (gets ever closer without crossing).
💡 Study aid — one-line memory hook. "Linear goes anywhere; logistic stays in the box." The box is 0 to 1.
〰️ Part 2 — The Sigmoid, the Two-Step Math & the Threshold▼

The sigmoid function — the heart of logistic regression

σ(z) = 1 / (1 + e^(−z))

It takes any real number z (from −∞ to +∞) and "squashes" it into a range between 0 and 1. The output is read directly as a probability.

Input zσ(z)Meaning
Large positive (e.g., 6)≈ 1 (0.9975)Very likely Class 1
0exactly 0.5Equally unsure — the most uncertain point
Large negative (e.g., −6)≈ 0 (0.0025)Very likely Class 0
  • Steep region — near the middle, a small change in input causes a large change in probability.
  • Why it matters — binary classification needs probabilities, not raw scores; the sigmoid turns predictions into probabilities.
⚠️ Not explained in the source: what e is. The deck uses it in the formula without defining it. The exact values 0.9975 and 0.0025 are calculated from the formula; the deck only says "≈ 1" and "≈ 0".

From linear equation to probability (two steps)

2 · Squashp = σ(z) = 1 / (1 + e^(−z))Pass z through the sigmoid to get a probability

  • The foundation — linear combination, then sigmoid: that two-step process is the entire foundation of logistic regression.

Decision boundary & threshold

  • Probability first — the model outputs a probability, e.g., p = 0.82.
  • Threshold — we convert that probability into a class using a threshold, commonly 0.5. The 0.5 point is the decision boundary.
  • Decision rule — p ≥ 0.5 → Class 1 · p < 0.5 → Class 0. So p = 0.82 → Class 1.
  • Adjustable — the threshold can move, depending on whether false positives or false negatives matter more.

🎯 Part 3 — Training (Log Loss), Types & Real-World Uses▼

The cost function: log loss (binary cross-entropy)

Cost = −[ y·log(p) + (1 − y)·log(1 − p) ] # y = the true label (0 or 1) p = the predicted probability
  • What it measures — how wrong a single prediction is. During training it's averaged across all data points.
  • Penalty shape — it heavily penalizes confident, wrong predictions, much more than a small, cautious miss.
  • How training uses it — the model adjusts its weights (via gradient descent) to minimize this cost over many training iterations.
💡 Study aid — reading the formula. Only one half of the bracket is ever "on". If y = 1, the second term is multiplied by 0, so Cost = −log(p): it wants p near 1. If y = 0, the first term drops out, so Cost = −log(1 − p): it wants p near 0.
⚠️ Not explained in the source: gradient descent (named only — how it adjusts the weights isn't covered) and the base of "log". The chart and the 0.11 / 2.30 values use the natural log; they illustrate the shape the lecture describes.

Types of logistic regression

TypeClassesExample
BinaryExactly two — the most common caseSpam vs. not spam · 0 vs. 1
MultinomialThree or more, no natural orderCat vs. dog vs. bird
OrdinalThree or more, with a natural orderLow vs. medium vs. high risk
💡 Study aid — two questions. How many classes? Two → binary. Three or more → can you rank them? Yes → ordinal (ordered). No → multinomial.
⚠️ Not explained in the source: how logistic regression is actually extended to multinomial or ordinal problems — the lecture only names and defines the types.

Real-world use cases

Use caseThe question it answers
Spam detectionIs this email spam, or not spam?
Medical diagnosisIs a disease present, or absent?
Credit scoringShould this loan be approved, or denied?
Customer churnWill this customer stay, or leave?
Ad targetingWill this user click the ad, or not?

Summary & key takeaways

  • Logistic regression predicts probabilities for classification, not continuous values.
  • Core math: linear combination → sigmoid → probability → threshold → class.
  • Trained by minimizing log loss using gradient descent.
  • A simple, fast, highly interpretable baseline model for binary classification.

B · np.meshgrid(np.arange(...), np.arange(...))Builds a dense grid of (age, salary) points covering the chart: from 10 years below the youngest to 10 above the oldest, and 1,000 below to 1,000 above the salary range, in steps of 0.25. X1 holds each point's age, X2 its salary.
C · plt.contourf(...)ravel() flattens the grids, np.array([...]).T stacks them into rows of (age, salary), sc.transform scales them, classifier.predict labels every point, and .reshape(X1.shape) folds the answers back into the grid. contourf then fills the background: red = predicted 0, green = predicted 1 (alpha = 0.75 = slightly see-through).
D · plt.scatter loopPlots each real training point, colored by its true label: red for 0, green for 1. enumerate(np.unique(y_set)) loops over the two classes.
LabelsTitle, axis names, and a legend showing 0 (red) and 1 (green).
  • The straight edge between red and green is the decision boundary — where the predicted probability is 0.5.
  • Pattern — older people and higher earners mostly fall in green (purchased). The edge runs from about age 30 at 150,000 down to about age 51 at 20,000.
  • Misclassified points — a red dot in green, or a green dot in red, is a training point the model got wrong.
  • Training set only — the notebook plots only the training data.
  • The warning printed above the chart — a Matplotlib UserWarning about the c argument. It's harmless; the chart still draws.
💡 Study aid — why the boundary is a straight line. p = 0.5 exactly when z = 0 (Part 2). And z = w₁·Age + w₂·Salary + b = 0 is the equation of a straight line. So logistic regression with two features always draws a straight decision boundary.
🔤 X / y reminder. X1 and X2 are grid coordinates (every age and every salary on the chart), not new features. X_set / y_set are just the unscaled training features and target, renamed for plotting.
